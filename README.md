# Orientation Dynamics and Rotational Charateristics of Ellipsoidal Particles in Simple Shear Flow

Undergraduate thesis repository — Muntaha Islam, Northwestern Polytechnical University.

## Physical model

A rigid, axisymmetric prolate spheroid (aspect ratio r) is suspended in an
incompressible Newtonian fluid under steady simple shear flow

    u = (γ̇ y, 0, 0)

in the Stokes regime (Re ≪ 1, zero particle inertia). The in-plane orientation
angle θ obeys the Jeffery equation

    dθ/dt = −(γ̇/2)[1 − λ cos(2θ)],   λ = (r² − 1)/(r² + 1).

Because the symmetry axis is undirected, orientations live on
−π/2 ≤ θ < π/2, and the axis period is

    T_axis = π (r + 1/r) / |γ̇|.

## Orientation statistics

From the periodic solution, the code computes three time-averaged
quantities and compares them with their analytic forms:

- orientation density p(θ) = √(1−λ²) / {π[1 − λ cos 2θ]}, normalized on −π/2 ≤ θ < π/2;
- order parameter S = ⟨cos 2θ⟩ = (r−1)/(r+1);
- dwell fraction P₁₅°, the time within ±15° of the flow axis, = (2/π) arctan[r tan 15°].

Samples are taken at uniform time intervals over several complete periods,
so the histogram is the true time-weighted density.

## Requirements

Python ≥ 3.10. Install dependencies with:

    pip install -r requirements.txt

## How to reproduce the results

Run the scripts from the repository root:

    python scripts/solve_jeffery.py
    python scripts/Shear.py
    python scripts/Case_B.py
    python scripts/case_C.py
    python scripts/orientation_statistics.py
